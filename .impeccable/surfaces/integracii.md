# Integrations surface

- Route: `/integracii/`
- Mode: Persuade
- Audience: Bulgarian business owners who want an AI employee to work with their existing software.
- Primary action: Send the name of a system for connection review.
- Proof: Named supported systems, visible work outcomes, and three honest setup levels.
- Chosen direction: Vertical connection rail, approved comp `.impeccable/mocks/integrations-switchboard-c.png`.
- Memorable moment: Existing Raboti agent artwork connects into one continuous rail that runs from the first viewport through the final CTA.
- Constraint: No generated agent portraits. No Zapier or Make. Copy is provisional until the second pass.

## Implementation fidelity

| Ingredient | Medium | Commitment |
|---|---|---|
| Continuous rail | HTML/CSS | Persists through every page section and becomes a narrow structural spine on mobile. |
| Agent artwork | Existing `AgentAvatar.astro` | Use Vdiga, Pomaga, and Pishe artwork already shipped by Raboti. |
| Source connections | Semantic HTML/CSS | Ten named first-wave systems; labels remain visible in the document. |
| Work receipt | Semantic HTML/CSS | Input, Raboti processing, and completed work remain readable without animation. |
| Primary action | Semantic link | Green in the hero, white in the closing section, with consistent wording. |
| Motion | CSS | Only the rail sockets pulse; reduced-motion users receive a static state. |

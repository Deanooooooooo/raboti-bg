# Agent wordmarks

Owner-supplied transparent WebP wordmarks for the three available Raboti roles.

- `*-wordmark-dark.webp`: use on white and pale surfaces.
- `*-wordmark-light.webp`: use on dark, photographic, or strongly colored surfaces.
- `pishe-wordmark-light.webp` has normalized foreground alpha for consistent solid-white rendering. The exact supplied half-alpha file is preserved in `source/`.
- Preserve each image's native aspect ratio and transparent background.
- Use the role name as alt text when the image replaces visible text. Use empty alt text only when the same role name is already adjacent.
- Prefer one identifying wordmark per role-focused region. Do not repeat the mark as decoration.
